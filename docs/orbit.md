# Orbit fullscreen listening

Select **Orbit** beside **Lyrics** at the top right. Orbit replaces the library inside the same native Sway window and enters fullscreen on the current display. When the side panel is hidden or the window is narrow, Lyrics and Orbit remain available together in the top-right toolbar. Escape or Exit restores the library, previous window dimensions and maximized/fullscreen state. Playback and the queue continue throughout. F11 toggles fullscreen without leaving Orbit. The optional monitor button moves this same window to another connected display.

The circular cover uses the song's actual artwork. The background is a heavily blurred, downsampled copy of that artwork, tinted toward its dominant color. Saturation is retained while brightness is capped for readable lyrics. Subtle dithering avoids visible color contours, and the old radial washes and outer halo outline have been removed. The blur is precomputed once per cover in a small 256×144 texture, rather than running a fullscreen blur every frame. The play/pause glyph uses a centered 24-pixel coordinate frame, and symmetric transport columns keep the pause button centered in the view.

The 64-band halo reads decoded PCM from the existing audio stream, using a 1,024-sample Hann-windowed FFT. Stronger attacks, transient emphasis, faster response and taller peaks make it more energetic; the cover pulses slightly with measured energy. The visualization does not synthesize a beat. PCM bytes are passed through unchanged. Analysis is bypassed outside visible Orbit and in Calm mode. The animation runs at about 30 Hz during visible playback; minimizing the window, pausing, exiting or choosing Calm mode stops animation work. Music continues when the window is minimized.

Synced LRCLIB lyrics show the current line with two surrounding lines on each side. Timing follows playback and seeking. Untimed lyrics remain scrollable; disabled, missing and unavailable lyrics show their real status. The lyrics toggle centers the artwork for a cover-only view. Lookup respects Settings and reuses the existing cache; word-level timestamps are not inferred.

Play/pause, previous/next, shuffle, repeat, volume, seek and queue controls operate the same session. The heart targets the playing song, independently of a selected library row. Controls fade after four idle seconds during playback and reappear with pointer/keyboard interaction. Keyboard focus and the open queue keep controls accessible.

Track information and lyrics use slightly larger typography for viewing from a second screen. A muted, two-pixel song progress line remains along the lower edge when the controls fade. It has no thumb or time labels and smoothly follows playback and seeking; the regular seek control remains available on interaction.

Verification includes PCM transparency/frequency/silence fixtures, muted native decoder/output checks, single-window Orbit entry/exit/fullscreen/minimize/restore, lyric rewind/seek, queue and current-song likes, responsive layout, centered glyph coordinates, saturated-red blur fixtures and actual public red-cover rendering. The Win32 smoke test checks that Orbit retains MainWindow's native handle and that exit preserves playback. Preview captures use isolated original sample lyrics and fixture/public cover imagery; they do not modify account data.
